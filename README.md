## 回读时间窗（边缘钟漂裁决）

边缘钟漂会让回读时间戳落在下发前。每张证落 **下发时 / 边缘时（原始边缘钟）/ 中心时（中心收证/校正时）** 三联，按可配置允许漂移 `W`（默认 300s，策略表 `时间窗策略`，兼容视图 `时间窗策略表`）裁决：

- **超大漂移硬拒（两口径共同）**：边缘时早于 `下发时 − W`（早端）或晚于 `中心时 + W`（晚端），`valid=0`、永不正式确认、永不校正。
- 轻度逆序/偏差（在 W 带内）按口径分叉，两种口径字面量：
  - **`以窗拒为准`（默认）**：校验失败即回读失败，结果 `时间窗拒绝`，无正式证。
  - **`以中心校正收证为准`**：用中心收到时落正式证，置校正标记（`是否校正/校正标记/校正 = 1`），核证仍可查原始边缘时。
- 核证对象必含 `边缘时`、`中心时`、`是否校正`、`valid`（另含 `原始边缘时`、`中心收证时`、`正式确认`、`逆序`、`超漂移`、`窗裁决` 等）。
- 正式确认集统一谓词：`结果='确认' AND 正式确认=1 AND valid=1`。贯验与放量门（`/api/放量门`）同口径排除超窗证、逆序被拒证与并发去重证；同票同边缘至多一张正式证（部分唯一索引 + `BEGIN IMMEDIATE` + 去重回查，并发双回读不双计）。

主要路由（均在 `/api` 下）：

| 路由 | 说明 |
| --- | --- |
| `GET/POST /时间窗策略`（别名 `/回读时间窗策略`，`PUT` 同） | 读/写口径与允许漂移秒；与站规 KV 双向同步 |
| `GET /核证`、`GET /核证/{证号}`（别名 `/回读核证`） | 核证列表/单张 |
| `POST /核证`、`GET/POST /回读时间窗` | 无状态试裁决 |
| `GET /正式确认集?票号=` | 正式确认证号集 |
| `GET/POST /放量门` | 正式确认集、缺失边缘、超窗排除、可放量 |
| `GET /回读证` | 回读台数据，含三联时刻与校正/valid 标记 |

前端「回读台」页可切换两种口径、一键装载五套时间窗夹具，并展示 **原始边缘时、中心收证时、校正标记、valid** 与放量门结论；「轨贯验」页展示正式确认/校正/超窗排除计数。

### 夹具与自动化

夹具在 `fixtures/时间窗-*.json`（时刻用相对偏移描述，不会过期）：正常时序、逆序、超大漂移（早/晚两端）、并发双回读、校正收证分叉。

```bash
# 先起后端（默认 http://127.0.0.1:11800，可用 FLAGRAIL_BASE 覆盖）
python3 scripts/时间窗_逆序.py        # 逆序：默认窗拒口径，不计入正式确认集
python3 scripts/时间窗_超大漂移.py    # 超大漂移两端 × 两口径，均不可当确认
python3 scripts/时间窗_正常时序.py
python3 scripts/时间窗_并发双回读.py
python3 scripts/时间窗_校正收证_口径分叉.py
bash scripts/跑全部时间窗自动化.sh

# 后端测试
cd backend && PYTHONPATH=. python3 -m pytest tests/ -q
```

「逆序」与「超大漂移」是两套分开跑的脚本，二者断言的证都不得计入正式确认集合。
